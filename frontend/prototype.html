FAQ 6개 · 질문 클릭

      

        
실전 자동매매를 시작하려면 어떻게 하나요?
페이퍼 검증을 마친 뒤 S07 페이퍼→실전 전환에서 3단계(전환 사유·리스크 안내·계좌 확인)를 완료하세요. 시작 전 S09에서 리스크 한도를 먼저 설정하는 것을 권장합니다.

        
백테스트 수익률이 실제와 다르게 나와요
수수료·슬리피지·세금 반영 여부를 확인하세요(S06 상단 파라미터 바). 과거 성과는 미래 수익을 보장하지 않습니다.

        
'한도 초과 주문 차단'이 떴어요
S09의 일일 최대 매수 금액(기본 ₩1,000만)과 오늘 사용액을 확인하세요. 한도를 조정하거나 다음 거래일로 미루면 됩니다.

        
전략을 예전 버전으로 되돌릴 수 있나요?
S13 버전 관리에서 롤백할 버전을 선택하고 '롤백'을 누르세요. 버전별 변경 내역 비교도 지원합니다.

        
시세가 멈춘 것 같아요
데모의 관심종목 피드는 2.6초 주기로만 갱신됩니다. 실제 매매 연동은 실제 증권사 API 연결이 필요하며, 이 데모에는 매매 기능이 없습니다.

        
이 서비스를 유료로 운영해도 되나요?
투자자문업·투자일임업 인가 요건이 적용될 수 있으며, 금융위 법령해석상 자동매매(일임) 방식은 유사투자자문업 범위에 포함되지 않습니다. 운영 전 반드시 법률 검토가 필요합니다.

연동 아키텍처 실제 구현 시

      
// 브라우저(SPA) → 백엔드 프록시 → Google API
SPA ── 주문/리포트 요청 ──▶ 백엔드 서버 ── OAuth 2.0 ──▶ Google APIs
                                        ├─▶ Sheets API   (거래·성과 기록)
                                        ├─▶ Drive API    (리포트·백업 저장)
                                        ├─▶ Apps Script (스케줄 트리거·이메일)
                                        └─▶ Gemini API  (AI 기능)

      
⚠️ 브라우저에서 Google API 직접 호출은 CORS 제약으로 불가합니다. 반드시 백엔드 프록시 경유 · API 키는 서버에만 보관(노출 금지) · OAuth refresh token 만료 대비 재인증 로직 필요.
